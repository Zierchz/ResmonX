Network control from the right-click menu.

## Changes
- **Network context menu**: right-clicking a connection now offers the process
  actions plus **Close connection**, which drops that single TCP connection
  without touching the process. The action is available on TCP over IPv4;
  Windows exposes no equivalent for IPv6, so those rows show it disabled.
- **Block a process or a remote IP**: new **Block the process's network** and
  **Block remote IP** actions, backed by the Windows Filtering Platform (the
  same user-mode mechanism simplewall uses, no kernel driver). Blocking also
  closes the live TCP connections, since a filter is only consulted when a
  connection is established. Rules are listed under a new **Rules** subtab in
  the Network section, where they can be lifted again. They are intentionally
  temporary: Windows removes every rule when ResmonX exits, so a forgotten
  block can never leave an app offline.
- **Context menu in the widget**: the floating widget's process table gained the
  same right-click menu as the main window, positioned to stay inside its small
  window.
- The Network section's process list now shows **every process** instead of only
  those moving bytes at that instant, so rows no longer appear and vanish on
  each refresh and the table keeps a steady size. Idle processes read 0.

Bandwidth limiting is not included: throttling requires a kernel-mode driver,
which ResmonX deliberately does not install.

## Install
Download and run `ResmonX-Setup.exe` (or `resmonx_0.9.0_x64-setup.exe`).
Requires Windows 10/11.

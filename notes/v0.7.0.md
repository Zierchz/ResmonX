Start with Windows and English translation.

## Changes
- **Start with Windows**: new toggle in the tray menu and in the settings
  (gear) popover. When Windows launches ResmonX at sign-in it stays minimized
  in the system tray, monitoring with alerts and widget available.
- **English translation**: the whole UI (views, tables, menus, dialogs, tray,
  notifications and widget) is now bilingual. Pick the language from the gear
  popover; with no explicit choice, ResmonX follows the system language and
  falls back to English.

## Install
Download and run `ResmonX-Setup.exe` (or `resmonx_0.7.0_x64-setup.exe`).
Requires Windows 10/11.
